# Roadmap

The current boundary is finite, sequential, adversarial tool outcomes with
bounded strong completion and portable positive and negative evidence.

Near-term work should improve the value of that boundary:

- More independently reviewed contract-change examples, especially identity,
  stale observations, and compound operations.
- Better author diagnostics mapping obstructed decisions to source outcomes.
- Additional mutation and fuzz campaigns, persisted regressions, and compiler
  differential coverage.
- More measured state-space families and explicit explanations of resource
  UNKNOWN, without implying unbounded scalability.
- Compatibility fixtures for future format revisions and external consumers.

Potential later work includes import/export adapters for established planning
formats and a separately reviewed runtime integration contract. Any live
execution layer would need its own authority, conformance, and concurrency
model.

Telemetry collection remains disabled until an approved first-party endpoint,
operator, retention policy, bounded transport, and new privacy tests exist.
No collection service or activation date is promised.

Automatic inference of reliable semantics from prose, production safety
guarantees, and unbounded liveness are outside the current roadmap. Ideas are
welcome, but each expansion must preserve explicit assumptions and independent
verification.
